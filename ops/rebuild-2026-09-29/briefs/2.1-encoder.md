## Design (Isaiah's classes; game form only at I/O)

- **Stems** (`ObservationInputStem(input_dim, trunk_cfg)`, one per entity group, input = float channels ‖ one-hot categorical fields):
  - `tile_proj`: 15 + 6 + 6 + 4 + 100 + 2
  - `actor_proj`: 26 + 241 + 100 + 4
  - `shop_proj`: 8 + 8
  - `market_proj`: 2 + 9
  - `player_feature_proj`: 44
  - `global_proj`: 15
- **Learned tokens** (separate `nn.Parameter`s, normal std `D**-0.5`, like Isaiah):
  - `player_tokens [2,D]`; the self and opponent tokens are each added to `player_feature_proj(player_features)`
  - `board_tokens [n_scratch,D]`
  - `actor_plan_tokens [1,D]`
  - `critic_value_tokens [2,D]`
- **Sequence:** `[own actors 241][rival actors 241][tiles 200][shops 8][market 9][players 2][global 1][board n][plan 1][critic 2]`. Mask: `actor_mask`, all-true tiles and market, `shop_mask`, `still_playing` expanded to the players, always-on global/board/plan, and critic tokens.
- **Trunk:** `nn.ModuleList(TransformerBlock(trunk_cfg) × depth)` plus `final_norm`. It reuses Isaiah's flash-packing path and compile hook (`compile_transformer_trunk`). Outputs are masked back to 0 as in Isaiah's `encode_observations`.
- **Named output** `KaggricultureEncoded`: `hidden`, `token_mask`, `own_actor_hidden [B,241,D]`, `player_hidden [B,2,D]`, `global_hidden`, `board_hidden`, `actor_plan_hidden [B,1,D]`, `critic_value_hidden [B,2,D]`. Offsets are computed from named counts, never bare literals.
- **Stateless:** `forward` / `evaluate_actions` / `compute_value` reject a hidden state (`_require_stateless`); the hidden-state methods are Isaiah's no-op defaults.
- **L6 guard:** before the compiled trunk, `rows × tokens × max(embed_dim·mlp_ratio, 3·embed_dim) < 2^31` (the largest GEMM inner dimension in a block), else raise `ValueError` naming the shape and pointing to `references/compiled-gemm-template-overflows-above-2-21-rows`. Chunking is out of scope; training shapes stay far below the limit.
- **Muon:** `get_input_layers` returns each stem's `.input`, the four token parameters and the actor input layer (added in 2.3). `get_output_layers` returns `critic_head.out` and the head `.out`s (2.2/2.3). Isaiah's `_excluded_from_muon_param_ids` then matches his rule by construction.

## Tests (written first; each must fail before the implementation)

1. `test_types.py`:
   - a synthetic batch passes `validate_shapes()`
   - a wrong channel count, a wrong enum range or a missing field raises with the field name
   - the enum constants equal the contract table
2. `test_topology_matches_isaiah_stateless_transformer`: build Isaiah's 6m (`configs/scaling_6m.yaml`, `force_flash_attn=False`) and ours, then check:
   - every shared role uses the same class (`ObservationInputStem`, `TransformerBlock`, `LayerNorm`)
   - the token parameters are separate per role, with shapes `[2,D]`, `[n,D]`, `[1,D]`, `[2,D]`
   - trunk config fields are equal except the documented game I/O
   - no `nn.Embedding` exists outside `actor.` (none at all in 2.1)
3. `test_encoded_fields_are_named_and_masked`: shapes of every `KaggricultureEncoded` field; masked tokens are exactly 0; absent actors don't affect present-token outputs (masking works).
4. `test_outputs_depend_only_on_current_observation`: running another observation in between doesn't change outputs; a hidden-state argument is rejected.
5. `test_seat_rows_are_encoded_independently`: changing seat 1's row doesn't change seat 0's encoding (no cross-seat leakage).
6. `test_trunk_size_guard`: the guard raises just above `2^31 / inner_dim` rows × tokens and passes just below. It uses a meta-device or shape-only check, **no large allocation on the Mac**.
7. `test_muon_exclusions_follow_isaiah_rule`: stem `.input` excluded, stem `.output` included; token parameters excluded.
8. Isaiah's suites stay green after the `BaseModelAPI` generic refactor: `tests/owl tests/scripts tests/tools`.
