## `types.py` manifest (contract v4) [R3]

All tensors have leading dims `[E, 2]`, where `F = 252`. Constants: `T = 200`, `A = 482`, `S = 8`, `P = 9`, `I = 12`.

| Group | Fields (dtype, trailing shape) |
|---|---|
| Tiles | `tile_kind`, `tile_crop`, `tile_animal`, `tile_cell`, `tile_role` (int64, `[T]`); `tiles_int` (int64, `[T,7]`); `tiles_float` (f32, `[T,15]`) |
| Actors | `actor_slot`, `actor_cell`, `actor_role` (int64, `[A]`); `actor_mask` (bool, `[A]`); `actor_inventory`, `actor_inventory_rank` (int64, `[241,I]`); `actors_float` (f32, `[A,26]`) |
| Players | `player_features` (f32, `[2,44]`); `storage_counts` (int64, `[17]`); `storage_rank` (int64, `[12]`); `banks` (f64, `[2]`) |
| Shops | `shop_type`, `shop_slot` (int64, `[S]`); `shop_mask` (bool, `[S]`) |
| Market | `market_product` (int64, `[P]`); `market_float` (f32, `[P,2]`); `market_int` (int64, `[P,2]`) |
| Globals | `global_features` (f32, `[15]`); `globals_int` (int64, `[16]`) |
| Masks and context | `still_playing` (bool, `[]`); `order_limits` (int64, `[]`); `action_mask: KaggricultureActionMask(can_act bool [F])` |

That's 29 top-level fields including `action_mask`. `validate()` checks:
- every dtype and trailing shape, and shared leading dims
- categorical ranges: kind < 6, crop < 6, animal < 4, cell < 100, tile role < 2, slot < 241, actor role < 4, shop type < 8, shop slot < 8, product < 9
- float channels finite

It allows negative sentinels, signed channels and large scaled values. It is called at env admission and in tests, never in the model hot path.

## Design (Isaiah's classes)

- **Trunk config [R7]:** a typed `StatelessTransformerV1Config` built from the validated shared fields (`embed_dim`, `depth`, `n_heads`, `mlp_ratio`, `activation`, `n_scratch_tokens`, `force_flash_attn`). It's used for `ObservationInputStem`, `TransformerBlock` and the packing and compile hooks. No duck typing.
- **Stems** [R3-verified widths]:

| Stem | Input | Width |
|---|---|---|
| `tile_proj` | 15 ‖ kind 6 ‖ crop 6 ‖ animal 4 ‖ cell 100 ‖ role 2 | 133 |
| `actor_proj` | 26 ‖ slot 241 ‖ cell 100 ‖ role 4 | 371 |
| `shop_proj` | type 8 ‖ slot 8 | 16 |
| `market_proj` | 2 ‖ product 9 | 11 |
| `player_feature_proj` | | 44 |
| `global_proj` | | 15 |

  One-hot uses fixed class counts, cast to the float-channel dtype.
- **Tokens:** separate `nn.Parameter`s: `player_tokens [2,D]`, `board_tokens [n,D]`, `actor_plan_tokens [1,D]`, `critic_value_tokens [2,D]`.
- **Rows:** `B = 2E`; each seat row is an independent batch row.
- **Sequence** (`T = 705 + n`, i.e. 709 at n = 4) [R4], with its token mask in the same order:

| Tokens | Count | Mask |
|---|---|---|
| own actors, rival actors | 482 | `actor_mask` |
| tiles | 200 | true |
| shops | 8 | `shop_mask` |
| market | 9 | true |
| players, each `player_tokens + player_feature_proj(player_features)`, added **before** the trunk | 2 | `still_playing`, expanded |
| global | 1 | true |
| board | n | true |
| plan | 1 | `still_playing` |
| critic | 2 | `still_playing`, expanded |

  This is Isaiah's pattern: player, plan and critic tokens are masked by `still_playing`.
- **Trunk:** `TransformerBlock × depth` and `final_norm`. Isaiah's flash-pack path when available; otherwise the padded mask. Outputs are re-masked to 0.
- `KaggricultureEncoded`:
  - `hidden [B,T,D]`, `token_mask [B,T]`
  - `own_actor_hidden [B,241,D]`, `player_hidden [B,2,D]`, `global_hidden [B,1,D]`, `board_hidden [B,n,D]`, `actor_plan_hidden [B,1,D]`, `critic_value_hidden [B,2,D]`
  - offsets come from named counts
  - `count_non_masked_tokens(obs)` equals `token_mask.sum()` [R4]
- **Initialization [R7]:** Isaiah's `reset_parameters` scheme:
  - hidden linears: orthogonal, gain √2
  - stem inputs: gain 1
  - residual outputs: gain 1/√(2·depth)
  - linear biases 0; LayerNorm 1/0
  - token parameters: normal, std `D**-0.5`
- **L6 guard [R5]:** `Kmax = max(D, H)` with `H = int(D·mlp_ratio)`, since Isaiah's attention uses separate D→D projections and the MLP is D→H→D; for this preset `Kmax = 512`. `M = B·T` for the padded path (conservative, labelled as such) and `x.shape[0]` for the packed path. If `M·Kmax ≥ 2^31`, the forward is chunked over rows (padded) or rejected with a pointer to the cookbook Reference (packed). The check runs before any trunk execution. Its scope is the recorded GEMM-template mechanism.
- **Muon [R6]:** `get_input_layers` = each stem's `.input`, plus `player_tokens`, `board_tokens`, `actor_plan_tokens` and `critic_value_tokens`. The actor input projection is **not** excluded; Isaiah doesn't exclude his `source_actor_input_proj`. `get_output_layers` is filled in by 2.2/2.3 (`critic_head.out`, head `.out`s).
- **Stateless:** every API rejects a non-`None` hidden state; a checkpoint carrying hidden-state keys is rejected.

## Tests (written first; each must fail before the implementation) [R8]

Behavioral checks run on CPU in inference mode with E = 1, a small width/depth and all entity slots present. No large tensors and no real compilation.

1. **Types:**
   - every dtype, leading dim, pinned size and categorical boundary (inclusive and exclusive edges)
   - negative sentinels, signed channels and scaled values above 4 all pass
   - a missing field, a wrong dtype or an out-of-range category raises, naming the field
2. **Topology vs Isaiah:**
   - build the 6m model from `configs/scaling_6m.yaml` (structure only, no forward)
   - shared roles use identical classes (`ObservationInputStem`, `TransformerBlock`, `LayerNorm`)
   - exact stem widths (133/371/16/11/44/15), block count 8, resolved trunk config equal to 6m's except depth
   - separate token parameters with shapes `[2,D]`, `[n,D]`, `[1,D]`, `[2,D]`
   - no `nn.Embedding` anywhere
   - Isaiah's initialization statistics on a tiny model
3. **Fields and masks:**
   - distinct marker values plus an identity-trunk stub prove every offset, and that player features are added before the trunk
   - masked tokens are exactly 0
   - perturbing masked actors **or masked shops** leaves present-token outputs unchanged
4. **Stateless:** every API rejects a non-`None` hidden state; recurrent checkpoint keys are rejected; the policy/value methods raise until 2.2/2.3.
5. **Seat isolation:** changing seat 1's row leaves seat 0's encoding unchanged **and** does change seat 1's (no constant-output false pass).
6. **Guard:**
   - `M_safe = (2^31 − 1) // Kmax` passes; `M_safe + 1` triggers
   - exact equality where divisible
   - the padded path chunks, the packed path rejects
   - a stub proves the decision happens before trunk execution
   - GELU and SiLU `H` are covered
7. **Muon:** the actual parameter groups from `create_optimizer` (no step):
   - stem `.input.weight` excluded
   - stem `.output.weight` included
   - token parameters excluded
   - actor input projection weight included
   - biases and norms go to AdamW
8. **Flash and compile (CPU-mocked, following Isaiah's `tests/owl/model/test_stateless_transformer_v1.py` patterns):** pack once and unpack once, correct masks and `max_seqlen`, `dynamic=True`, the requested compile mode, unchanged state-dict keys and correct dispatch.
9. **Generics typing:** a probe module checked by mypy:
   - bare `BaseModelAPI` is Orbit
   - `KaggricultureTransformer`'s forward/serve outputs are typed Kaggriculture actions
   - mixing the games' observations or specs is a type error
10. **Regressions:** Isaiah's suites, project mypy (`py-static`) and `cargo test`.
