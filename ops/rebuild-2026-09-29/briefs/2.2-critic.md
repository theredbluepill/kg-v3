# Brief — Task 2.2: Isaiah's critic on the Kaggriculture encoder (Claude)

- **Design** (Isaiah's `StatelessTransformerV1` critic, `docs/model-architecture.md` "Critic"):
  - `critic_head = OutputProjectionMLP(trunk_cfg, 1)`, applied to `critic_value_hidden [B,2,D]` (self, opponent), gives logits `[B,2]`
  - masked `log_softmax` over the two players (both are active until the game ends) gives the winner distribution
  - `value = 2·p(self) − 1` (`win_loss`); `compute_value` returns `[E,2]`
  - `winner_log_probabilities(obs)` returns `[E,2,2]` for value distillation (Phase 4)
- **Output layer:** `get_output_layers()` returns `(critic_head.out,)`, initialized with Isaiah's critic gain 1.0 (orthogonal, zero bias) and excluded from Muon; `critic_head.up` uses Muon.
- **Scope:** `value_mode` is fixed to `win_loss`. Gamma 1 and MSE value loss are trainer settings (Task 3.4). Returns stay in [−1, 1] via `terminal_scale` (contract, reward section).
- **Tests:**
  - `compute_value` shape `[E,2]` and range (−1, 1)
  - `value == 2·exp(logp[...,0]) − 1`; the probabilities sum to 1
  - the head is an `OutputProjectionMLP` with output width 1 applied per token (a shared head)
  - swapping the two critic-token hidden states swaps the players' probabilities
  - output-layer initialization gain 1; Muon exclusion of `critic_head.out.weight`, inclusion of `critic_head.up.weight`
  - hidden state rejected
  - seat independence of values
