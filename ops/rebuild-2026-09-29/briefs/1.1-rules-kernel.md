### Workspace, path dependency and L4

**Decision proposed for Claude:** do not create a shared workspace or a root path dependency in Task 1.1. The root `Cargo.toml` has no `[workspace]`, no engine dependency, and root `src/` has no engine consumer. A nested independent Cargo package needs neither a root workspace entry nor a root dependency. Its own lockfile and explicit `--manifest-path` commands give a separate feature resolution. Keep root manifest/lock/source byte-identical.

Task 1.2 lives inside the engine package. Task 1.3's planned `src/kaggriculture/observe.rs` may become the first root consumer when compiled against `Game`; Task 1.4 certainly will. Add the path dependency at the **first actual compiled consumer**, after reviewing that task, rather than claiming nothing before 1.4 can need it. There is no consumer that justifies it in **this** task.

Workspace membership is not a dependency edge, but it is also **not feature isolation**. Cargo's locally installed primary documentation (`share/doc/rust/html/cargo/reference/resolver.html`, “Features”, in `nightly-2026-04-18-aarch64-apple-darwin`) explicitly states that selecting multiple workspace packages with `--workspace` or multiple `-p` flags unifies dependency features; separate invocations avoid that unification. A shared workspace also shares lock resolution. Resolver 2/3 does not isolate a normal engine dependency from the root's active test dependency on the same `serde_json` package. A root-only default invocation can avoid the engine when no dependency selects it, but `cargo test --workspace` would reintroduce L4.

Keep engine `serde_json` features `arbitrary_precision` and `preserve_order`: removing them breaks the kernel's tested unbounded integer/numeric and ordered-inventory semantics. If Claude chooses a shared workspace now, the minimal way to keep unmodified root decoding is **separate package test invocations** (never selecting both); the more robust choice is the standalone package proposed here. Once the root needs the path dependency, apply the reference's narrow test-only repair, not feature deletion:

```rust
// src/rules_engine/generation.rs, test RandomCall::Uniform only:
Uniform {
    #[serde(deserialize_with = "fixture_float")]
    low: f64,
    #[serde(deserialize_with = "fixture_float")]
    high: f64,
    #[serde(deserialize_with = "fixture_float")]
    value: f64,
},

fn fixture_float<'de, D: serde::Deserializer<'de>>(deserializer: D) -> Result<f64, D::Error> {
    serde_json::Number::deserialize(deserializer)?
        .as_f64()
        .filter(|number| number.is_finite())
        .ok_or_else(|| serde::de::Error::custom("expected a finite fixture number"))
}
```

This handles Serde's tagged-enum buffering of arbitrary-precision decimals as Number's private map. The exact reference diff is obtainable with `git diff HEAD kg/reference-2026-09-29 -- src/rules_engine/generation.rs`. It is **not applied in Task 1.1**. Reopen L4 when adding a root dependency/workspace; test the affected generation fixtures red before the decoder repair, then require 155 passed / 2 ignored unchanged.

## Appendix A: Manifest schema and checker

`TRIM_MANIFEST.json` uses strict schema version 1. Paths are repository-relative, with forward slashes. `retained` has exactly the 12 paths above; `excluded` has the other 113. Each retained entry includes both reference and resulting SHA-256 and an ordered array of line edits. An edit uses **one-based original** `start_line`, `delete_lines` (zero means insertion), exact UTF-8 `insert` text, and a nonempty `reason`. Reconstruct the final file from original bytes and the declared edits; a changed digest alone is insufficient. Binary fixtures must have an empty edit list. `authored` lists new engine files with resulting hashes and reasons. The manifest cannot hash itself; it is the sole explicit inventory exception. Build output under `engine_rs/target/` is ignored, but extra source, test, fixture or metadata files fail verification.

The generator in Appendix C supplies all values directly; there are no placeholder hashes. This checker is a consistency/provenance check, not a signature or semantic proof. A reviewer must assess declared edits, and Cargo/tests must assess behavior.

Create `scripts/check_engine_trim.mjs` with:

```javascript
import assert from 'node:assert/strict'
import { createHash } from 'node:crypto'
import { execFileSync } from 'node:child_process'
import { readFileSync, readdirSync, lstatSync } from 'node:fs'
import { resolve, join } from 'node:path'
import { pathToFileURL } from 'node:url'

export const PIN = '65f0eac5bb00b18a9d3acce319c2a231cbd5dff0'
export const sha = bytes => createHash('sha256').update(bytes).digest('hex')
const keys = (value, expected) =>
  assert.deepEqual(Object.keys(value).sort(), [...expected].sort(), 'schema keys')
const reason = value => assert.equal(typeof value === 'string' && value.trim().length > 0, true, 'reason')
const validPath = path => {
  assert.equal(typeof path, 'string')
  assert.match(path, /^engine_rs\//)
  assert.equal(path.includes('\\'), false)
  assert.equal(path.split('/').some(part => ['', '.', '..'].includes(part)), false)
  assert.equal(path.startsWith('engine_rs/target/'), false)
  assert.notEqual(path, 'engine_rs/TRIM_MANIFEST.json')
}
const sameSet = (a, b, label) => assert.deepEqual([...a].sort(), [...b].sort(), label)

export function verify(manifest, originals, current) {
  keys(manifest, ['schema_version', 'reference_commit', 'retained', 'excluded', 'authored'])
  assert.equal(manifest.schema_version, 1)
  assert.equal(manifest.reference_commit, PIN)
  const seen = new Set()
  for (const entry of [...manifest.retained, ...manifest.excluded, ...manifest.authored]) {
    validPath(entry.path)
    assert.equal(seen.has(entry.path), false, `duplicate: ${entry.path}`)
    seen.add(entry.path)
  }
  sameSet([...manifest.retained, ...manifest.excluded].map(e => e.path), originals.keys(), 'reference inventory')
  sameSet([...manifest.retained, ...manifest.authored].map(e => e.path), current.keys(), 'current inventory')
  for (const entry of manifest.excluded) {
    keys(entry, ['path', 'reference_sha256', 'reason'])
    reason(entry.reason)
    assert.equal(sha(originals.get(entry.path)), entry.reference_sha256, `${entry.path}: reference hash`)
    assert.equal(current.has(entry.path), false, `${entry.path}: excluded file present`)
  }
  for (const entry of manifest.retained) {
    keys(entry, ['path', 'reference_sha256', 'sha256', 'edits'])
    const original = originals.get(entry.path)
    const actual = current.get(entry.path)
    assert.equal(sha(original), entry.reference_sha256, `${entry.path}: reference hash`)
    assert.equal(sha(actual), entry.sha256, `${entry.path}: current hash`)
    let expected = original
    if (entry.edits.length) {
      const text = original.toString('utf8')
      assert.deepEqual(Buffer.from(text), original, `${entry.path}: edits require UTF-8`)
      const lines = text.match(/[^\n]*\n|[^\n]+$/g) ?? []
      let cursor = 0
      const parts = []
      for (const edit of entry.edits) {
        keys(edit, ['start_line', 'delete_lines', 'insert', 'reason'])
        reason(edit.reason)
        assert.equal(Number.isSafeInteger(edit.start_line), true)
        assert.equal(Number.isSafeInteger(edit.delete_lines), true)
        assert.equal(typeof edit.insert, 'string')
        const start = edit.start_line - 1
        assert.equal(start >= cursor && start <= lines.length && edit.delete_lines >= 0, true, `${entry.path}: edit range`)
        assert.equal(start + edit.delete_lines <= lines.length, true, `${entry.path}: edit end`)
        parts.push(lines.slice(cursor, start).join(''), edit.insert)
        cursor = start + edit.delete_lines
      }
      parts.push(lines.slice(cursor).join(''))
      expected = Buffer.from(parts.join(''))
    }
    assert.deepEqual(actual, expected, `${entry.path}: undeclared edit`)
    if (entry.path.endsWith('.rs') && entry.path !== 'engine_rs/src/lib.rs') {
      assert.equal(entry.edits.length, 0, `${entry.path}: retained Rust must be unchanged`)
    }
  }
  for (const entry of manifest.authored) {
    keys(entry, ['path', 'sha256', 'reason'])
    reason(entry.reason)
    assert.equal(sha(current.get(entry.path)), entry.sha256, `${entry.path}: authored hash`)
  }
}

export function check(root) {
  // Largest pinned blob is 5,099,830 bytes; include excluded blobs in custody.
  const git = args => execFileSync('git', args, { cwd: root, maxBuffer: 16 * 1024 * 1024 })
  const paths = git(['ls-tree', '-r', '--name-only', PIN, 'engine_rs']).toString().trim().split('\n')
  const originals = new Map(paths.map(path => [path, git(['show', `${PIN}:${path}`])]))
  const current = new Map()
  function walk(relative) {
    for (const name of readdirSync(join(root, relative))) {
      const path = `${relative}/${name}`
      if (path === 'engine_rs/target' || path === 'engine_rs/TRIM_MANIFEST.json') continue
      const stat = lstatSync(join(root, path))
      assert.equal(stat.isSymbolicLink(), false, `${path}: symlink`)
      if (stat.isDirectory()) walk(path)
      else {
        assert.equal(stat.isFile(), true, `${path}: not a regular file`)
        current.set(path, readFileSync(join(root, path)))
      }
    }
  }
  const manifest = JSON.parse(readFileSync(join(root, 'engine_rs/TRIM_MANIFEST.json'), 'utf8'))
  walk('engine_rs')
  verify(manifest, originals, current)
  const retained = ['Cargo.toml', 'Cargo.lock', 'LICENSE', 'VENDORED_FROM.md',
    'src/lib.rs', 'src/py_random.rs', 'src/econ_attrib.rs', 'tests/py_random.rs',
    ...[95324500, 95901360, 95921764, 95990191].map(id => `fixtures/episode-${id}.jsonl.gz`)]
  sameSet(manifest.retained.map(e => e.path), retained.map(p => `engine_rs/${p}`), 'Task 1.1 retained set')
  const newPaths = manifest.authored.map(e => e.path)
  assert.equal(newPaths.every(p => p === 'engine_rs/tests/replay_parity.rs'), true, 'Task 1.1 authored set')
  const removed = new Set([19, 21, 22, 23, 24, 25, 27])
  const lib = originals.get('engine_rs/src/lib.rs').toString().split(/(?<=\n)/)
  const expectedLib = Buffer.from(lib.filter((_, i) => !removed.has(i + 1)).join(''))
  assert.deepEqual(current.get('engine_rs/src/lib.rs'), expectedLib, 'exact seven removals')
  assert.equal(sha(expectedLib), 'c4b9bac5057be3a435d2f1035aae17bcd15e7f95ea8557322e4929877c8231fd')

    .replace('[[bin]]\nname = "re_engine"\npath = "src/main.rs"\n\n', '')

  assert.deepEqual(current.get('engine_rs/VENDORED_FROM.md').subarray(0, oldProvenance.length), oldProvenance, 'append-only provenance')
}
```
