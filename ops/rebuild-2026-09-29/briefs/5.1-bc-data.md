## Selection behavior retained and deliberate changes

`scripts/kaggriculture_bc/select_replays.py` uses only Python's standard library.
Supply the physical source root explicitly; the implementation has no v2 path,
legacy model names or engine dependency:

```sh
python scripts/kaggriculture_bc/select_replays.py SOURCE_ROOT SELECTED.zip
```

For each day 21 through 27 inclusive, it sorts `.json` member names,
shuffles with `random.Random(20260929 + day)`, then selects the first 36.
The first 4 are validation, the next 32 training: **28 validation + 224 training**.
Selection applies no outcome, player or opponent filter; preparation uses both
seats. The date-prefixed output member, split, source archive/member, payload
SHA-256 and payload byte count retain the historical manifest field names.

The duplicate check was in reference `prepare.py`, **not** the selector. It is
moved earlier: reject repeated selected **episode basenames**, even in different
directories/dates/splits, rather than deduplicate or resample. Identity is the
archive's filename convention, not a claimed inspection of JSON `info.EpisodeId`.
The preparation boundary should cross-check that field when present. Duplicate
JSON ZIP entries and unsafe member paths also fail. A short source day now raises
instead of silently producing fewer than 36 episodes. Existing output files are
never overwritten and failed copies remove their incomplete output. Source ZIPs
remain read-only. The external convenience list is omitted; the authoritative
`selection.json` is embedded in the output ZIP.

ZIP container bytes are not a reproducibility criterion: write timestamps and
compression may differ. Compare IDs, splits and uncompressed payload hashes;
record the new ZIP's own hash when transferring it. The old ZIP hash above is a
custody check only for that existing artifact.

The independent synced corpus inventory in the source receipt's `manifest.json`
contains every day's `episode_files`. The port reproduces all **252** historical
source-member IDs in order and the **224/28** split; inventory byte lengths match
the reference selection. Raw selected JSON totals **8,940,727,054 bytes**. This
checks selection without reading or downloading those payloads. See
`../checks/stream-d-source-audit.json` for source hashes, method and exact scope;
the final check receipt is `../checks/stream-d-results.md`.

## What prepare.py must rebuild for contract v4

1. **Parse and validate provenance first.** Strictly validate the selection
   schema, duplicate identity, hash and length before encoding. Replace `assert`
   custody checks (disabled by Python `-O`) with explicit errors. Validate episode
   configuration and required observations, and keep per-episode/turn rejection
   reasons. Configuration/state envelope failures must be distinguishable from
   codec admission failures; never silently clamp, truncate or substitute fields.
2. **Keep temporal alignment and paired admission.** For each
   `t in range(len(steps) - 1)`, observation is `steps[t][seat].observation` and
   submitted action is `steps[t+1][seat].action`. Discover shared observation
   keys from `specification.observation[*].shared` and reconstruct seat 1 only
   from those seat-0 fields. Keep each seat's own `private` object. Admit a pair
   only if **both** labels encode; the reference counts one rejection per paired
   turn, stopping at the first seat error. Keep original turn indices in shard
   metadata so rejected gaps never become a fictional consecutive trajectory.
3. **Use the rebuilt offline explicit-state constructor/writer.** Assemble public
   `step/day/hour/farms/market/town` plus both private views and full legal config.
   Feed the same native observation writer used by v3 caller-owned buffers; do
   not reconstruct features in Python or reuse `MyolieBuffers`, flat features,
   their suffix or legacy `context`. Historical seed 0 was an offline encoding
   placeholder, not the actual replay seed. An observed snapshot does not recover
   hidden RNG state: encoding it is valid; stepping it as an exact continuation
   is not. Seed-based full replay belongs to Task 7.3.
4. **Preserve ordered JSON maps.** Inventory and shed insertion order is now
   explicit (`actor_inventory_rank`, `storage_rank`). Preserve zero-count keys,
   omitted keys and removal/reinsertion order through JSON → native `IndexMap`;
   never `sort_keys=True` or treat rank as item-enum order. Add checks on states
   with identical counts but different key orders. Normalized tensors must use
   exact native integer state, not rounded legacy float features.
5. **Emit all named observation tensors.** Schema 3 carries tile categories and
   exact fields, actors/masks/counts/ranks, own storage, ordered shops, market
   integer/float channels, players, globals, banks, order limits and action mask.
   Enforce contract shape/dtype/role order: leading `[turn,2]`, 200 tiles, 482 actor
   slots, 241 own inventory rows, 8 shops and 9 products. Exact integer tensors
   are int64; observation banks float64; masks bool; float channels float32.
   Preserve applicable −1 sentinels, zero inapplicable fields, signed/unbounded
   scaled values and zero/masked padding. Do not expose rival-private inventory,
   RNG, replay labels or opponent identity to actor or critic.
6. **Adopt v4 actions from the native grammar/codec.** Store int64
   `[turn,2,252,12]` tokens and `[turn,2]` lengths, with every own actor frame,
   ordered market frames, one STOP included in length and zero padding thereafter.
   Fix `unit_target=0`, use `hire_limit=241`, preserve empty market orders and
   explicit market quantity zero, and distinguish omitted transfer quantity from
   positive 1–1023. Reject unsupported syntax, excess hand commands, overlong
   market queues and quantities instead of clipping. Affordability is an engine
   result, not an admission mask. Reuse the native grammar's enum/mask source.
7. **Resolve the omission discrepancy explicitly.** The reference preparation
   comment and historical cookbook said omitted units become `NONE`, but the code
   inserts Python `None`, and `actor_codec._unit_frame` rejects it as a nonempty
   list violation. Grammar unit kind 0 is structural, not an actor no-op; v4 uses
   `PASS` for an explicit actor no-op. Do not copy the false comment. Preserve
   strict rejection initially; any future normalization to PASS needs an engine
   equivalence check, explicit admission accounting and documented count delta.
   The recorded corpus has no omission-specific rejection, so this inspection
   alone does not show that its measured 158,772 admitted pairs are wrong.
8. **Bound memory and version artifacts.** Flush native batches/shards and copy
   published buffers before reuse; avoid concatenating an entire episode/corpus
   into resident arrays as the old script did. Buffer concurrency must honor v4
   lifetime rules. Record schema/config/source hashes, episode/seat/turn identity,
   tensor names/dtypes/shapes, admission/rejection counts and shard SHA-256/bytes.
   Episode IDs and opponent metadata are custody labels, never model inputs.
   Reject old `features/context` shards by schema, rather than silently loading
   them into the new model. No old arrays or old BC checkpoint are v4-compatible.

## Deferred acceptance and questions

The reference manifest records **181,188 paired turns** (252 × 719), with
**158,772 admitted = 139,835 train + 18,937 validation**, and **22,416 rejected**:

| First rejection | Pairs |
|---|---:|
| Unknown market command | 14,007 |
| Unsupported unit command arguments | 5,621 |
| Market item syntax mask | 1,668 |
| Extra hand commands | 1,102 |
| Market queue limit | 17 |
| Quantity range | 1 |

Future preparation must match episode membership/split and these admission totals,
or provide a per-episode/turn explanation of differences caused by the v4 contract
or repaired admission. New observation fields require their own source-state
checks; reproducing counts is not feature correctness. Independently compare
encoded tensors on evolved states, private-seat isolation, key-order changes,
sentinels, shop duplicates/positions, config boundaries and large exact integers.
Round-trip admitted labels through the new native grammar and check effective
actions. Native explicit-state ABI, v4 tensor parity, real-payload hashes, full
admission replication and pod reachability remain pending. This selector does
not complete Task 5.1 preparation or qualify BC policy quality.
